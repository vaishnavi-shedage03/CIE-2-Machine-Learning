# Activity 1: Dataset Preparation

## Objective
To perform data preparation and basic exploratory data analysis on the Students Performance dataset.

## Dataset
Students Performance in Exams dataset from Kaggle.

## Tasks Performed
1. Loaded the dataset using Pandas.
2. Inspected the first and last five rows.
3. Checked dataset shape, columns and data types.
4. Generated statistical information.
5. Identified and handled missing values.
6. Checked and removed duplicate records.
7. Created visualizations using Matplotlib and Seaborn.
8. Encoded categorical variables.
9. Scaled numerical features using StandardScaler.
10. Saved the prepared dataset as a CSV file.

## Tools and Libraries
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Output
Prepared dataset: `Prepared_StudentsPerformance.csv`

## Conclusion
The dataset was inspected, cleaned and transformed into a prepared format suitable for further machine learning tasks.
